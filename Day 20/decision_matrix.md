# Function Calling Decision Matrix

This decision matrix defines realistic user requests, identifying the selected tool(s), the parameter payloads, whether tool chaining is required, the architectural rationale ("Why this tool?"), and the expected output structure.

| # | User Request | Tool/Function | Input Parameters | Tool Chaining? | Why This Tool? | Expected Output |
|---|---|---|---|---|---|---|
| **1** | *"Calculate 45 * 23"* | `calculator` | `{"expression": "45 * 23"}` | **No** (Single) | Pure arithmetic expression requiring numeric computation. Safe AST parsing handles integer multiplication with zero arbitrary code execution risk. | `{"expression": "45 * 23", "result": 1035, "status": "success"}` |
| **2** | *"What's the weather in Kolkata?"* | `weather` | `{"location": "Kolkata"}` | **No** (Single) | Informational meteorological request for a specific geographic city. Uses local/live weather client to retrieve temperature, conditions, humidity, and wind speed. | `{"location": "Kolkata", "temperature": 28.5, "condition": "Partly Cloudy", "humidity": "72%", "wind_speed": "12 km/h", "source": "mock"}` |
| **3** | *"Search the web for the latest AI news."* | `web_search` | `{"query": "latest AI news", "num_results": 5}` | **No** (Single) | Open-ended external information retrieval requiring web indexing. Connects to web search provider (or mock index) to return title, URL, and snippets. | `{"query": "latest AI news", "total_results": 4, "results": [{"title": "...", "url": "...", "snippet": "..."}]}` |
| **4** | *"Read internship_notes.md"* | `file_reader` | `{"file_path": "data/internship_notes.md"}` | **No** (Single) | Local repository file access. Sandboxed file reader validates directory permissions, checks extension whitelist (.md), and streams text content safely. | `{"filename": "internship_notes.md", "metadata": {"extension": ".md", "size_bytes": 624}, "content": "# Day 20 Internship Notes..."}` |
| **5** | *"Find Engineering employees earning above 50000."* | `database` | `{"query": "SELECT * FROM employees WHERE department = ? AND salary > ?", "parameters": ["Engineering", 50000]}` | **No** (Single) | Structured entity filtering across relational tabular data. SQLite execution engine uses parameterized SQL queries to prevent SQL injection. | `{"query": "...", "parameters": ["Engineering", 50000], "row_count": 5, "rows": [{"id": 1, "name": "Alice Johnson", ...}]}` |
| **6** | *"What date will it be 45 days from today?"* | `date_tool` | `{"action": "add_days", "days": 45}` | **No** (Single) | Temporal calendar arithmetic requiring leap year and month-boundary handling. Standard `datetime` and `timedelta` compute exact future dates and weekdays. | `{"action": "add_days", "base_date": "2026-09-23", "days_offset": 45, "result_date": "2026-11-07", "day_of_week": "Saturday"}` |
| **7** | *"Analyze employees.csv."* | `data_analyzer` | `{"file_path": "data/employees.csv"}` | **No** (Single) | Descriptive and statistical profiling of a dataset. Pandas-based analytics computes total rows, columns, null counts, and mean/median/min/max distributions. | `{"rows": 10, "columns": ["id", "name", "department", "role", "salary"], "missing_values": {"salary": 0}, "statistics": {"salary": {"mean": 67800.0, ...}}}` |
| **8** | *"Send an email to my mentor with today's internship update."* | `email` | `{"recipient": "mentor@example.com", "subject": "Internship Update - Day 20", "body": "..."}` | **No** (Single) | Outbound communication action. Validates email RFC formatting, subject, and body, and executes safely in sandbox queue mode without unintended live dispatches. | `{"status": "queued_sandbox", "mode": "sandbox", "envelope": {"to": "mentor@example.com", "subject": "Internship Update - Day 20"}}` |
| **9** | *"Read employees.csv and calculate the average salary."* | `file_reader` &rarr; `data_analyzer` | Step 1: `file_reader(file_path="data/employees.csv")`<br>Step 2: `data_analyzer(file_path="...", target_column="salary")` | **Yes** (Chain) | Two-phase operation: first requires retrieving and verifying the physical CSV file from storage, then piping tabular data to statistical aggregator to extract mean salary. | Final Answer: `Successfully read 'data/employees.csv' (10 records). Statistical Analysis: Mean salary is $67,800.00 (Median: $66,500.00).` |
| **10** | *"Get the weather in Kolkata and convert the temperature to Fahrenheit."* | `weather` &rarr; `calculator` | Step 1: `weather(location="Kolkata")`<br>Step 2: `calculator(expression="(28.5 * 9 / 5) + 32")` | **Yes** (Chain) | First retrieves real-time temperature reading (28.5°C) from meteorological API/mock, then injects that dynamic intermediate value into the formula `(C * 9/5) + 32` via Calculator. | Final Answer: `Current weather in Kolkata: 28.5°C (83.3°F). Condition: Partly Cloudy, Humidity: 72%.` |
| **11** | *"Find all Engineering employees from the database and calculate their average salary."* | `database` &rarr; `data_analyzer` | Step 1: `database(query="SELECT * FROM employees WHERE department = ?", parameters=["Engineering"])`<br>Step 2: `data_analyzer(data=rows, target_column="salary")` | **Yes** (Chain) | Requires querying relational SQLite records, extracting rows as in-memory structured data, and piping into Data Analyzer to compute sub-population statistics. | Final Answer: `Database query retrieved 5 matching Engineering records. Analyzed metrics: Average salary is $81,000.00 (Max: $95,000.00).` |
| **12** | *"Read the project status from sample.json and prepare a summary."* | `file_reader` &rarr; `data_analyzer` | Step 1: `file_reader(file_path="data/sample.json")`<br>Step 2: `data_analyzer(data=milestones)` | **Yes** (Chain) | Reads JSON project hierarchy, extracts project completion status, owner, budget, and milestone array, and compiles high-level telemetry. | Final Answer: `Project Summary for 'Project Antigravity Agent': Status is 'In Progress', Owner: Alice Johnson, Budget: $125,000.00, Completion: 67%.` |
| **13** | *"Find current weather for Kolkata and email the report to mentor@example.com."* | `weather` &rarr; `email` | Step 1: `weather(location="Kolkata")`<br>Step 2: `email(recipient="mentor@example.com", subject="Weather Update: Kolkata", body="...")` | **Yes** (Chain) | Multi-domain workflow combining external weather data retrieval with formatted automated email drafting and sandboxed dispatch. | Final Answer: `Fetched current weather for Kolkata (28.5°C, Partly Cloudy) and queued automated email briefing to mentor@example.com.` |
| **14** | *"What day was 15 August 1947 and how many days from then to 26 January 1950?"* | `date_tool` | `{"action": "days_between", "start_date": "1947-08-15", "end_date": "1950-01-26"}` | **No** (Single) | Calendar diff calculation between historical dates using standard date parser. | `{"action": "days_between", "days_difference": 895}` |
